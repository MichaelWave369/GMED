04 / SCIENTIFIC METHOD

A difference is not a discovery.

Both paths start with the same proposed comet state. The second includes an approximate Earth–Moon gravitational perturbation, including acceleration of the heliocentric origin. Their divergence measures a sensitivity to model assumptions.

Changing the integration start date changes the result. Turning the mass factor above or below 1× is a deliberately counterfactual experiment. Half-step agreement checks numerical consistency, not ancient astronomy.

Before claiming historical accuracy, we need true Earth and Moon ephemerides, a gravity-aware orbital fit to the ancient source constraints, and independent comparison against the published sky figures.
