03 / WHAT STILL REMAINS

Imported isn't authenticated.
Calculated isn't observed.

A forged text file can pass header checks. The exported receipt records SHA-256 hashes so source bytes can be reproduced and independently inspected, but a hash alone cannot prove NASA issued the file.

Beyond this gate, a rigorous study must record authoritative DE441 data provenance, use a verified calendar and timescale conversion, re-fit candidate comet orbital states using full dynamics, and compare against independent software.
